# 光伏组串IV扫描台

扫描员提交组串开路电压、短路电流与填充因子。写入后走 PostgreSQL 通知通道叫醒独立工人，工人不轮询空转。填充因子不低于 0.72 为合格，否则衰减。页面是 Vue 3。

## 汇流箱端子座位

每笔扫描必须先点选汇流箱端子排再提交，按箱设座位上限做容量管控：

- 端子排满员后不许再往该箱塞新扫描：满员笔**整笔退回**（不写扫描单），只在「挡回痕迹」留痕，接口返回 409。
- 占位与扫描单在同一事务提交，**随单冻住**；事后改座位上限不影响旧单已占座位。
- 末席对撞靠事务内 `SELECT … FOR UPDATE` 锁箱行串行化，并发两笔只可能一笔占住、另一笔退回名额。
- 顶栏「端子座位」专页三格：左=各箱已占（空箱显示「还没有占位」）、中=座位上限（仅扫描员可改）、右=挡回痕迹。
- 观察员（watcher）可翻阅占位与痕迹，但不能改上限、不能入队（403）。

种子：甲箱 0 占位（可把上限调成 1 验证满员），乙箱已占 2 席。

## 技术栈

- 后端：Litestar、Uvicorn、psycopg 同步写入
